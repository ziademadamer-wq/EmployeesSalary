a small project is designed by C# and WPF and ADO.Net.
I’ve learned a bit about how to use WPF and ADO.NET.
that project was a small excercise on using 3-Tier Architecture (Data Access Liar , Business Liar and Presentation Liar)
,CleanCode , inheritance and some of C# concepts.
The project has 2 sources to extract data from :
1-Json File is already saved with file
2- Database from sql server 
to extract Database from sql server the backup file is saved on ( SQL Data ) Folder and enter to DataBaseReader Class to type your Server Name that you will contact to.
as for Json file it is saved also on (Json Data) Folder and you need to open Business Layer class and write the File Path on the Constructor.
all uou need to do is select the Storage Type you want through a message box will appear to you as you open the app.
